# SQL Mini Project – Retail Sales Analysis

## Project Overview
This project focuses on analyzing a retail sales transactions dataset using SQL. The project includes data validation, business analysis, customer insights, CASE WHEN statements, CTE queries, and sales trend analysis.

---

## Dataset Used
Retail Sales Transactions Dataset

The dataset contains:
- Transaction details
- Customer information
- Product categories
- Quantity sold
- Revenue data

---

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate Functions
- CASE WHEN
- CTE (Common Table Expression)

---

## Project Tasks
- Data validation and cleaning
- NULL value check
- Duplicate transaction check
- Revenue analysis
- Customer spending analysis
- Sales trend analysis
- Product category analysis

---

## Key Insights
- Clothing category generated the highest revenue.
- Adult customers contributed the highest sales.
- Monthly sales trends showed revenue variation across different months.
- Some product categories performed above average revenue.
